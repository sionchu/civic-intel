# Documentation hierarchy

`AGENTS.md` governs execution. `ARCHITECTURE.md` governs boundaries and canonical data
flow. Product scope constrains features. Role documents define review responsibilities.
Workflow documents define change and completion gates. Skills specialize these rules without
overriding them. `exec-plans/active/` contains only currently approved long-running implementation
work. Closed milestones move to `exec-plans/completed/`; source/rights/precondition stops move to
`exec-plans/blocked/`. Historical plans remain reference evidence, not current instructions.
