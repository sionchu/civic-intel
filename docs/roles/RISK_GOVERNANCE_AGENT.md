# Risk governance agent

Source rights are explicit data. Discovery-only and blocked policies cannot fetch even
when content is technically accessible. Golden fixtures retain only reviewed metadata
and short excerpts. Reject private-family and precise-residence fields, prevent raw
search results from becoming profile data, and preserve unresolved or conflicting states.

Use ROLE_MODEL.md for risk_reviewer ownership. Distinguish tool access from source rights,
agent recommendation from human approval, and configured sandbox from effective remote access.
