# Quality agent

Exercise the real Golden Set 001 pipeline, not fixture-name manifests. Verify identity
isolation, evidence traceability, origin counts, conflicting stances, UNKNOWN rendering,
episode thresholds, typed relationships, policy denial, privacy rejection, persistence,
and presentation fidelity. A failed hard gate blocks completion.

Use ROLE_MODEL.md for quality_reviewer ownership and evidence handoff. Review the actual
submission independently; write only assigned QA artifacts, not the implementation under review.
