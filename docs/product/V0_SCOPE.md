# V0 scope

V0 proves a policy-first pipeline from one deterministic official-source fixture through
normalization, resolution, provenance, atomic evidence, verification, API, and a small
roster/profile UI. The golden framework contains ten representative people.

Private-family discovery, precise residence, broad crawling, paywall bypass, payments,
and distributed infrastructure are prohibited. Live connectors remain optional and
must have an explicit SourcePolicy before use.
